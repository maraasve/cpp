# 42 C++ Modules

A collection of C++ projects completed as part of the 42 curriculum. These modules focus on learning modern C++ concepts, object-oriented programming, memory management, and software design through hands-on projects.

## Overview

The C++ modules introduce fundamental and advanced C++ concepts, progressing from basic syntax to more complex topics such as inheritance, polymorphism, templates, and the Standard Template Library (STL).

Each module contains exercises designed to reinforce specific concepts and develop practical problem-solving skills.

## Modules

| Module        | Topics                                                                     |
| ------------- | -------------------------------------------------------------------------- |
| CPP Module 00 | Namespaces, classes, member functions, initialization lists, and basic I/O |
| CPP Module 01 | Memory allocation, pointers, references, and switch statements             |
| CPP Module 02 | Ad-hoc polymorphism, operator overloading, and the Orthodox Canonical Form |
| CPP Module 03 | Inheritance                                                                |
| CPP Module 04 | Subtype polymorphism, abstract classes, and interfaces                     |
| CPP Module 05 | Exceptions                                                                 |
| CPP Module 06 | C++ casts                                                                  |
| CPP Module 07 | Templates                                                                  |
| CPP Module 08 | Templated containers, iterators, and algorithms                            |
| CPP Module 09 | STL containers and algorithms                                              |

## Compilation and Usage

Each exercise can be compiled from its respective directory using `make`, provided a Makefile is included.

```bash
cd cpp00/ex00
make
```

Run the resulting executable according to the exercise requirements.

## Learning Objectives

* Apply object-oriented programming principles in C++.
* Understand memory management, pointers, and references.
* Implement inheritance and polymorphism.
* Work with exceptions, templates, and type conversions.
* Use STL containers, iterators, and algorithms.
* Write modular, maintainable, and reusable code.
